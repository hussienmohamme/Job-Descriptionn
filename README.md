# ميثاق الأدوار التعليمية — شركة مدارس النبلاء الأهلية

الأوصاف الوظيفية لخمس وظائف قيادية في قطاع التعليم:
الوكيل المقيم، مدير وحدة الأداء التشغيلي للعمليات التعليمية، مدير وحدة القياس الداخلي، مدير وحدة القياس الخارجي، مدير وحدة الأثر.

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى مستودع جديد.
2. من Settings ثم Pages اختر الفرع `main` واضغط Save.
3. يظهر الموقع على: `https://<اسم-الحساب>.github.io/<اسم-المستودع>`

الموقع ملف واحد (index.html) والشعار مضمّن داخله، وملف logo.png نسخة منفصلة للاستخدام عند الحاجة.
